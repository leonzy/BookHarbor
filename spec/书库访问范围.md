# 书库访问范围

## 1. 定义

书库访问范围决定读者能发现哪些书籍版本和格式文件。管理员可以按来源目录、独立的权限分类、用户及用户组设置范围。

**不是什么：**它不是下载、编辑等操作能力的开关，不替代私藏保护，也不是普通标签。获得某本书的可见性不代表获得下载或修改能力。

## 2. 使用场景

- 管理员让孩子只浏览儿童读物目录。
- 家庭成员共用一组规则，仍各自保留私藏。
- 同一本书的公开 EPUB 与受限 MOBI 分别提供给不同读者。
- 管理员先预览游客可见书目，再应用目录限制。

## 3. 功能

- 管理用户范围、用户组、目录限制和权限分类。
- 按书名、作者或 ISBN 查找书籍，或批量填写编号维护权限分类。
- 保存草稿、后台准备、取消准备、预览与应用。
- 统一过滤浏览、检索、目录、分类、统计、推荐、版本、阅读、下载和外部访问。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 用户范围 | user ceiling | 对单个用户的可见范围约束 | 小明只能浏览儿童读物 |
| 用户组 | group | 共享范围规则的一组账号 | 家庭组包含小明和小红 |
| 权限分类 | permission class | 管理员维护的权限专用书目集合 | 将《儿童百科全书》加入儿童读物分类 |
| 资源限制 | resource rule | 对目录或分类指定许可对象 | 财务资料目录只允许父母组 |
| 草稿 | draft | 尚未生效的规则 | 保存小明的新范围后先检查 |
| 准备变更 | prepare | 在后台计算可见书目 | 准备儿童目录规则时仍使用当前规则 |
| 检查影响并应用 | review and apply | 核对预览后切换规则 | 确认游客只能看到公开书目 |

## 5. 行为逻辑

未配置范围时保持原有公开和私藏规则。管理员能管理全部书目；普通读者和游客均受到适用的范围限制。账号删除后重建不会继承旧账号的稳定权限身份。

范围模式为“不额外限制”“仅以下范围”和“禁止浏览”。同一范围内多个目录或分类取并集；用户范围与其所属各组范围取交集。资源同时命中多个限制时必须全部满足，每条限制内许可用户或用户组取并集。空的选定范围不能保存，不会转为公开。私藏只属于原所有者，范围规则不能将其公开。

目录使用稳定来源身份，默认包含子目录，可改为仅当前目录。挂载不可用时不扩大访问，来源恢复后增量核对。复制、转换和分离的派生文件继承来源限制；共有书目元数据若含私藏祖先则按私藏处理，来源所有者冲突时不提供给普通读者。不能通过换格式、同作品合并、移动目录或复用账号编号绕过限制。

权限分类独立于可编辑的普通标签。分类成员变更属于草稿，只有完成准备并应用后才影响读者。编辑中的未保存更改在离开页面前提示确认。

管理员可在资源限制中显式勾选解除历史来源规则的继承，保存后必须准备、预览并确认应用。解除只针对所选历史规则，不能扩大私藏、当前目录或人员范围已有的约束。

准备期间显示进度，当前规则继续使用。准备可取消，进程重启后从持久化进度继续。应用需核对所选用户预览并确认；规则版本或来源水位已变化时拒绝过期应用，重新预览后再试。所有阅读进程通过兼容性检查后才允许应用。

列表先限定可见范围，再统计、分页和排序；文件大小只使用允许的格式。未授权格式不参与详情、目录路径、封面共享或下载。无法确定来源格式的历史封面与音频，只有全部来源格式均允许访问时才提供，避免衍生资源泄漏。

直接地址、OPDS、WebDAV、阅读器、设备发送与播客同样检查范围。签名令牌不能替代当前授权；权限变化后旧缓存不能继续返回内容，正在传输的响应在后续检查时停止，已传出的数据无法收回。
