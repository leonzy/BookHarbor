# MCP

## 1. 定义

MCP 是 BookHarbor 面向 Agent 的内置插件，通过 Model Context Protocol 提供受读者权限约束的查书、图书详情、元数据编辑、阅读记录、推荐、投递、在线导入和任务查询工具。它支持 Streamable HTTP 与本机 stdio 两种入口，共用站点的插件启停状态、读者权限和书库访问范围。HTTP 由个人连接或实例连接的令牌识别读者，stdio 用本机进程指定读者。

**不是什么：**

- 不是独立用户体系，也不允许 Agent 自己选择读者身份。
- 不是任意文件、网址、SQL、Shell 或 Calibre 参数执行入口。
- 不是大语言模型服务；推荐在书库内完成，不上传阅读记录给模型提供商。
- 不是永久任务队列；临时确认和 MCP 任务只保留在当前服务进程内。

## 2. 使用场景

- 读者让 Agent 找馆藏中的某位作者、某个主题或某本书。
- 读者让 Agent 汇总自己的在读、已读、书架和阅读进度。
- 读者提出「推荐几本轻松的科幻，不要我读过的」，Agent 返回馆藏候选及理由。
- 读者先确认书、格式和设备，再让 Agent 投递；重复请求不会重复执行。
- 读者通过已有书源导入一本书，并持续查询任务状态。
- 管理员只允许本机 Agent 查书，不允许远程访问或任何写入。

## 3. 功能

- MCP 初始化、工具发现和八个受控工具。
- 馆藏搜索、当前读者阅读记录、带理由的馆藏推荐。
- 编辑元数据、推送和在线导入的预检、明确执行、幂等和任务查询。
- 本地 Cookie、连接 Bearer 和显式读者 stdio 三种身份入口。
- 实例连接与用户连接，细粒度授权范围。
- 默认关闭远程访问与写操作。
- 私藏书、目录访问范围、读者能力与插件启停的一致校验。
- 不返回物理路径、密文、其他用户记录或原始内部异常。

## 5. 行为逻辑

### 5.1 插件与连接

插件默认停用。HTTP 调用还需建立启用的连接并授予相应授权范围；stdio 只要求插件已启用和本机执行权限。停用插件或连接后，已有 HTTP 令牌立即失效，但连接配置与加密凭据保留。插件卡片上的「个人 MCP 配置」在启停状态下均可打开，展示当前账号、站点地址与 stdio 配置；只有显式点击生成或显示时才返回本人令牌。

实例连接由管理员维护，必须显式关联一位读者；用户连接天然归属创建它的读者。实例连接不会让调用方获得管理员身份，所有数据权限都按关联读者计算。

登录用户可从头像菜单的「个人 MCP 配置」直接进入个人配置，不要求管理员身份。插件中心和个人插件设置的「个人 MCP 配置」显示当前登录用户名及 MCP 地址。使用者点击生成后，由系统生成个人令牌并关联当前登录账号，可复制令牌或带地址和令牌的 Agent 配置。状态查询不返回令牌，点击显示才读取本人令牌。重新生成会使该个人配置的旧令牌立即失效。个人配置面向 HTTP 客户端，默认允许携带令牌远程连接，写入默认关闭并可单独开启。已存在的其他类型连接仍按其原有规则处理。

手工建立的连接默认同时关闭远程访问和写操作；页面生成的个人连接明确用于远程 HTTP，因此允许远程但默认只读。非本机 HTTP 调用必须使用 Bearer，且连接必须允许远程；本机 HTTP 可以使用当前登录 Cookie 或 Bearer。stdio 由本机执行权限授权，用登录用户名或读者编号选择身份，并校验当前读者与访问范围。插件在站点启用后即可使用，默认只读。允许写入时由启动命令显式声明。

### 5.2 只读工具

馆藏搜索只返回当前读者可见的书籍。阅读记录永远限定为当前读者，不接受读者编号参数。推荐综合自然语言要求、当前读者阅读偏好和可见馆藏，排除已读、在读、已有进度及不可见书籍，并给出匹配理由。

所有工具只返回书目、格式大小、阅读状态和任务等公开字段，不返回文件物理位置。查询失败使用脱敏错误，不能把 SQL、凭据或上游响应原文带给 Agent。

### 5.3 写入确认与幂等

编辑元数据、推送和导入默认执行预检。预检重新验证书籍可见性、读者能力、格式或书源连接，并返回十分钟后过期的操作标识和摘要，不产生外部副作用。

执行必须同时提供预检操作标识、明确确认和非空幂等键。执行前再次校验，避免过期权限被复用。同一读者、工具和幂等键只创建一个任务；重复调用返回原任务。操作标识只能由创建它的读者使用。

书籍详情、搜索和推荐均只返回当前读者有权访问的格式与大小。管理员或私藏书所有者可编辑书名、作者、标签、出版社、丛书和 ISBN。未指定的可选字段保留原值，改动受手工元数据保护。每个预检标识只允许提交一个写任务。

读者可以列出自己的发送设备，通过预检和确认新增、修改或删除单个设备。发送书籍时可以指定本人设备编号和所需格式。确认前后设备信息变化时要求重新预检，避免误发。设备事务与其他短写入发生锁冲突时进行有限重试，并在每次重试中重新校验预检快照；仍失败时返回脱敏错误。

推送使用既有设备连接和馆藏格式。在线导入只能使用当前读者可用的既有书源及其书籍外部标识，不接受服务器路径或任意下载地址。任务只能由创建它的读者查询；服务重启后旧任务不可查询，不能据此推断写入被回滚。

### 5.4 协议

HTTP 与本机 stdio 都使用 JSON-RPC 2.0。HTTP 工具列表按连接授权与写入开关展示，stdio 按启动命令的写开关展示；缺少工具授权时，即使手工构造调用也会拒绝。通知不返回响应。MCP 使用协议自身的 result、error 和工具错误结果，不套用网页 API 的旧错误信封。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表 | 关键约束 |
|---|---|---|
| MCP 连接与授权 | `plugin_connections` | 复用所有者、配置和 scopes；手工连接默认关闭远程与写入，个人连接允许远程且默认只读 |
| Bearer 凭据 | `plugin_secrets` | 加密保存 `access_token`，公开序列化不返回 |
| 调用审计 | `plugin_runs` | HTTP 经插件运行时记录 |
| 阅读记录 | `reading_state` | 始终限定当前读者 |
| 临时操作与任务 | 进程内映射 | 操作十分钟过期；任务不落库，重启不可查询 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/mcp` | Streamable HTTP JSON-RPC；本地 Cookie 或 Bearer |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.combo.mcp` | 稳定的内置插件身份 |
| 能力 | `integrations.mcp` | 类型化 `MCPProvider` 能力 |
| 协议版本 | `2025-06-18` | MCP 协议版本 |
| 只读工具 | `book_search` `book_detail` `device_list` `reading_history` `book_recommend` `task_status` | 查询与任务读取 |
| 写入工具 | `book_update` `device_manage` `book_send` `book_import` | 两阶段受控写入 |
| 授权范围 | `books.read` `reading.read` `books.write` `tasks.read` | 工具级最小授权 |
| 连接配置 | `allow_remote` `allow_write` `user_id` | 默认关闭远程和写入；实例连接关联读者 |
