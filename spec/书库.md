# 书库

## 1. 定义

书库是**一个 Talebook 实例所管理的全部藏书**，以及把书送进来、找出来、清出去的全部手段。它是站点最核心的容器：所有书籍、元数据、阅读状态最终都挂在这一个书库上。

一个实例只有一个书库。书库的书目与文件由 Calibre 管理，Talebook 在其之上叠加导入流程、可见性过滤与浏览筛选。

**不是什么：**

- **不是单本书。** 一本书自身的字段与文件属于 [书籍](书籍.md)。
- **不是外部内容。** 书源提供的在线书籍在保存到本地之前不属于书库，见 [网络书库](网络书库.md)。
- **不是个人清单。** 收藏、书架是读者与书的关系，属于 [阅读状态](阅读状态.md)。
- **不支持多书库。** 没有「切换书库」的概念。

## 2. 使用场景

- **部署者第一次装好站点**，需要把已有的一堆电子书文件批量导进来。
- **读者想在几千本书里找到一本**，靠关键词或按维度逐层筛。
- **上传者从浏览器传一本大文件**，网络不稳，希望断了能续。
- **管理员把一批新书放进服务器目录**，希望系统自动发现并入库。
- **管理员误删了书**，想找回来。
- **读者只想看自己传的私藏书**。

## 3. 功能

- 书籍列表中的封面支持点击放大预览；书名和简介打开详情新标签页，保留列表筛选和页码。

- 浏览全部藏书，按维度筛选与排序。
- 关键词搜索。
- 最近上架、热门榜单、随机推荐等入口。
- 网页上传单本或多本书，大文件分片续传。
- 扫描服务器目录，批量查重与导入。
- 自动监控指定目录，有新文件时自动导入。
- 从外部 OPDS 服务器批量导入。
- 查看、恢复与清空回收站。
- 查看仅自己可见的私藏书。

书库卡片、封面网格、图书管理和详情按格式显示登记时的文件大小，使用 B、KiB、MiB 等单位；ZIP 成员显示解压后的书籍大小，展示大小不触发解压。未知大小不标成零。

仅索引也提取 EPUB、MOBI、AZW、AZW3 的内嵌封面，PDF 使用首页；原文件没有可用封面时使用默认图。提取的封面按书籍独立保存于站点数据目录，压缩到最长边 800 像素且不超过 512 KiB，不写入外部书籍目录，不保存书籍正文副本。已有封面优先保留，历史图书可后台补齐封面。

## 5. 行为逻辑

首页推荐在可见且来源可用的书籍中，结合读者收藏、想读、阅读记录及作者、标签、系列匹配排序，并降低同作者和同系列重复；无兴趣记录时优先热度、评分和入库时间。新书按入库时间排序，推荐数量服从站点配置。推荐只加载有界候选元数据，完整书卡仅加载最终结果。

导入的“停止当前任务”会停止手工及自动导入，保留已完成结果和未处理记录，并持久暂停自动监控；重启不会恢复被用户停止的任务。再次扫描或导入时解除暂停。容器退出导致的中断保留扫描目录队列、当前目录文件游标与导入意图；未被主动暂停的任务重启后继续。


### 5.1 可见性过滤

书库的每一个列表入口——浏览、搜索、分类、榜单——都**必须应用可见性过滤**：

- 管理员看到全部书。
- 登录读者看到公开书，加上自己收藏的私藏书。
- 游客只看到公开书。

过滤是**集合相减**而不是逐条判断：先取出当前访问者无权查看的私藏书集合，再从结果中排除。判断规则见 [书籍](书籍.md)。

### 5.2 上传

上传接受格式白名单内的文件。大文件走**分片上传**：初始化、逐片提交、最后合并。分片存在的原因是反向代理与浏览器都对单请求体积有限制，整本上传会在网络抖动时前功尽弃。

文件写入临时目录后立即做媒体分析，确定它是有效的电子书还是漫画容器，损坏或伪装的文件在此被拒绝。

游客能否上传由站点开关控制，默认**关闭**。

### 5.3 扫描与导入

管理员可以直接点击“全部导入”，无需选择书籍。后台按目录任务处理已有待处理书籍与增量发现的候选，优先继续未完成范围，按批次自动入库，ZIP 内成员也会自动导入。该按钮无论是否勾选都保持显示；重复启动合并到正在运行的同一导入任务。仍可单独扫描或按需导入勾选项。

导入任务保存启动管理员与导入方式，服务正常退出后自动继续剩余记录及目录扫描。普通文件的分析与元数据读取最多四路预取，书目按顺序写入并查重；ZIP 成员继续按临时空间预算逐本处理。大小与修改时间未变化、且使用当前分析规则的文件可复用扫描分析。

入库保存文件中提取的 ISBN、全部作者、出版社与语言；结构化字段缺失时继续尝试版权页和正文明确标注。历史书籍补全独立限速运行并优先处理新书，不阻塞导入队列；人工字段保护和联网匹配规则见 [元数据](元数据.md) 。

查重先识别内容完全相同的文件，再按有效 ISBN、净化书名和作者判断书目身份，规则见 [书籍](书籍.md) 。扫描时不使用文件名相同作为丢弃依据。已有格式槽位被不同文件占用时保留为另一版本；旧书籍后台关联作品，保留所有书号与来源记录。

封面提取在后台持久队列处理，最多两路并发，重启后继续；失败保留原因并延迟重试。书目先可浏览，封面完成后显示，正文不复制。兼容性规则更新后，显式全量核对重新检查相关 EPUB 失败记录；确认可读的回到待导入，仍失败的保留具体原因，相同文件不会重复重检。 扫描入口只做浅层可读检查，不写入测试文件或预先遍历目录，避免预检改变目录状态而触发重复扫描。

**扫描**遍历导入目录，为每个文件登记一条候选记录，并计算内容指纹用于查重。候选记录有自己的状态：

默认“增量扫描”检查已知目录状态，只读取变化或未知目录的文件列表，并处理持久保存的文件变化事件；未变化目录不重新枚举全部文件。首次没有目录快照时建立一次明确可见、可暂停续跑的基线。停止后“继续上次任务”恢复未完成队列与当前目录游标；暂停期间该目录发生变化时重读当前目录，避免漏掉游标之前的新文件。“全量核对”是独立确认入口，重新枚举所选范围，保留既有书籍与人工信息，不重复导入全部书籍。可填写具体容器目录仅处理该范围。目录不可用时保留快照和未完成任务，不据此删除书籍；文件系统监控事件存在缺口时提示手动全量补偿，不静默将默认操作变成全量。

页面在运行、暂停、等待恢复及完成时保留任务范围、扫描类型、阶段、当前路径、目录检查量、文件检查量、通过检查、实际入库图书、跳过和失败计数。发现期间总量可增加，不显示未知总量的百分比；检查累计量与实际入库图书数分开。内部批次大小不限制整次任务总数。普通电子书优先于通用压缩包，ZIP 成员仍分批入库，临时文件按原有预算清理。扩展名截断为 `.a`、`.az` 或 `.` 的文件，仅在实际文件头确认为 MOBI 容器时按 AZW3 识别，保留原文件名和位置。

ZIP 合集自动展开包内支持的电子书及嵌套 ZIP，逐本识别、查重和登记；纯图片 ZIP 仍作为漫画容器。扫描每次只解出当前一本临时文件，分析后清理，避免把全部压缩包同时解压占满磁盘。成功展开的容器本身不计作一本书；未变化的包重扫时跳过，旧版失败的小说 ZIP 可以重新识别。损坏、加密、路径越界、符号链接或超过处理预算的条目记录失败，其他条目继续。RAR 仍按已有漫画容器规则处理。

导入 ZIP 中的书时自动再次解出并校验内容。复制和移动模式写入内置书库；仅索引模式只保存原包、成员位置和内容校验信息，不永久保留解出的正文。阅读、下载、推送和转换时按需解压，操作结束立即删除，扫描与按需解压共享 512 MiB 临时空间硬上限，超限明确提示失败，不继续写盘。ZIP 内成员只读，编辑前须导出为普通文件。原 ZIP 在所有模式下保留。若源包在扫描后发生变化，旧条目不能继续导入，需重新扫描。

| 状态 | 含义 |
|---|---|
| 新发现 | 刚扫描到，尚未判定 |
| 待导入 | 判定为新书，可以入库 |
| 已存在 | 书库中已有同一内容，跳过 |
| 已跳过 | 重复、过小文件或扫描时源文件已不存在，不再等待导入 |
| 排队中 / 导入中 | 已提交导入 |
| 已导入 | 成功写入书库 |
| 失败 | 导入出错，保留错误信息 |

导入记录分为“待处理”“成功文件”“失败”“已跳过”。已存在相同内容或对应格式的重复记录也归“已跳过”，不算成功文件。已跳过记录保留供查询，不参与导入，也不计入待处理；已有跳过记录立即使用同一分类，无需重新扫描。总数等于四类数量之和，ZIP 展开容器不计入候选文件总数。导入页分别展示实际书籍数、可浏览书籍数、成功处理文件数和来源缺失书籍数。实际书籍按书目去重并包含确认缺失的书籍；可浏览数扣除确认缺失，实际浏览仍按访问权限过滤。同一本书可有多个成功文件；来源缺失只使用已通过挂载保护核实的结果。自动监控的周期扫描与手动全量任务完成状态区分，不能凭后台扫描判定全量导入尚未完成。切换分类后保持列表加载提示，收到列表结果才结束加载；后台进度刷新独立更新，不提前关闭列表加载提示。

内容指纹**全局唯一**，同一个文件不会被登记两次。

管理员可以设置最小导入文件大小，默认 10 KiB（1 KiB 为 1024 字节），0 为关闭。小于阈值的文件不登记为新候选、不计算内容指纹，也不入库；恰好等于阈值可处理。目录扫描、自动发现、增量和全量扫描共用该规则，ZIP 中每本书按解压后大小判断，不以外层 ZIP 的压缩大小拒绝合集。既有待导入记录在入库前复核实际大小，过小的归入已跳过并保存原因。调低阈值后，重新扫描能发现此前过滤的小文件，不因未变化的目录或 ZIP 快照而漏掉。

在导入设置保存阈值后，后台核查已入库的候选文件，按当前实际大小自动移除过小文件的登记；原文件保持原位，不删除、移动或复制。多格式书仅移除过小的格式，仍有其他版本则保留书目，最后一个版本移除时删除该书目登记。已入库文件的大小记录用于筛选候选，清理前仍需复核源文件；实际已增大的、不可读的、缺失的、挂载受保护或身份变化的文件保留。核查限速并在文件或导入批次提交后穿插少量处理；可点击“立即执行”使当前任务优先运行，重复点击保留游标，完成后可重新核查。当前文件未完成时明确显示等待原因，不取消或重置导入。完整来源核对与核查可并行，来源同步只写回仍存活且路径匹配的格式，不恢复已移除的登记；进度与游标持久保留，重启继续。导入页显示初始候选数、已核查文件数、移除的文件版本和书目数、不可读或受保护数量及错误。关闭阈值停止核查；设置改动不删除原文件。

**默认使用仅索引模式**，正文保留在挂载的源目录，不另行复制到内置书库。复制和移动需要管理员显式选择。

**导入**把全部或选中的候选写入书库，并按导入方式处理文件：仅索引保留源路径；复制保留源文件并写入内置书库；剪切在书库副本写入和登记成功后删除源文件。默认内置书库与 Calibre 数据库仍位于 `/data/books/library` ，外部挂载目录仅作为导入源。

管理员可以填写容器内任意可读的绝对目录，也可以从目录选择器浏览选择。目录列表至少包含一个目录，支持多个挂载目录，不另设允许目录白名单或默认导入目录。保存后刷新、手动扫描和自动监控使用相同的目录列表与导入方式；重启后配置保留。

**自动监控**开启后，后台首先完整发现已配置目录，随后按文件事件合并扫描新增或修改的文件及目录子树，走同一条查重与导入链路。无变化时不重复遍历目录或读取书籍内容；处理期间收到的事件保留到下一批，重复事件合并。关闭后停止新书自动导入。目录不可访问或导入失败时显示错误；已经判定重复并跳过的文件也视为完成，不因保留临时唯一指纹而反复计算整本书的内容校验值。重启、来源配置变化、事件丢失或监控恢复需要重新建立完整发现基线；无法使用原生事件时以 15 分钟间隔进行恢复核对，并显示监控错误。

### 来源文件同步

已索引书籍在配置的来源目录内删除、移动或改名时自动同步。启动时建立完整基线；Linux 文件事件合并约 1 秒后只核对受影响路径与子树，使用物理来源路径、文件身份与缺失大小索引查找相关记录。文件移动的事件分批到达时仍可识别原来源；跨文件系统先复制再删除通过未登记物理文件的路径与大小索引找候选，再核对内容，关闭新书自动导入时仍生效。索引仅保存元信息，不保存正文副本。每 30 秒只检查根目录挂载身份及健康标记，无变化时不遍历目录或查询全库。事件丢失、配置变化与挂载恢复时重新建立基线，遍历与内容校验耗时取决于目录规模。此能力独立于新书自动导入开关，关闭自动导入仍会同步已入库书籍。已打开网页在下次刷新时显示结果。

移动、改名更新来源路径，保留书籍 ID、书名、元数据、封面、收藏和阅读记录。同文件系统优先核对文件身份；跨文件系统使用入库时的内容校验值，多个候选不能唯一确认时不自动关联。目标需位于配置的来源目录中。ZIP 移动更新成员引用，不保留解压副本。

某个格式确认消失后不再作为可用格式展示；全部格式都缺失时从可读书库、分类书目、推荐和 OPDS 书目中排除，图书管理和个人历史仍保留书籍。原路径恢复或重新识别到移动目标后恢复可用，不重置已成功入库记录，也不重复创建书目。该处理不删除书目，也不删除或复制源文件。

目录无法访问、遍历不完整、根目录或子挂载身份变化、健康标记不可用时，暂停该目录的缺失判定，保留上次确认的状态。写入结束、提交前再次核对来源健康，期间失联则回滚本次状态变化。仅文件身份、大小或修改时间变化而可用性未变时，不应引起缺失、恢复和目录计数变化。可写来源根目录保存一个小型健康标记；只读来源依赖文件系统身份，并对空目录保守暂停。挂载恢复且身份和健康检查通过后继续同步；身份变化的目录需管理员核实后重建基线，不能自动当作批量删除。来源同步状态包含最近对账时间、各目录健康原因与变化计数。

挂载身份取来源目录所在的最深挂载和其子挂载，优先读取文件系统 UUID，并使用根 inode 与挂载拓扑；重启导致的设备号或设备名变化不视为来源更换，也不导致未改变的源文件全部重新校验内容。容器重建产生的无关父挂载变化不应影响正常来源。无法确认稳定文件系统身份时保持保护；不能用 F2FS 中同样依赖设备号的 statfs 标识绕过保护。旧版身份摘要不匹配时仍保持保护，不能仅凭根目录身份和健康标记自动升级；管理员需核实完整来源后显式重建。显式重建基线要求完整遍历非空目录、管理员核对身份与提交前身份复核；该动作本身不改变书目可用性。

### 5.4 从 OPDS 导入

管理员可以登记外部 OPDS 服务器，浏览其目录并批量导入书籍。导入是异步的，可查询进度、查看失败清单并重试失败项。这与读者侧使用 OPDS 客户端订阅本站是**方向相反**的两件事，见 [外部访问](外部访问.md)。

### 5.5 浏览与筛选

书库列表支持按元数据维度筛选与排序。维度定义见 [元数据](元数据.md)；排序规则统一：评分、日期、丛书、入库时间默认从新到旧或从高到低，其余字段升序，不认识的排序字段回退为按入库顺序倒序。

已确认属于同一作品的书目在浏览、分类和搜索结果中合为一张卡片，分页总数使用合并后的数量；卡片汇总可见成员的格式与文件大小，各文件仍保留原书号和详情入口。权限及筛选在合并之前执行，不能因不可见或筛选范围外的版本而漏掉结果。文件目录仅合并选定范围中的成员，树节点计数仍表示实际书目数。具体身份规则见 [书籍](书籍.md)。

分类维度可能有上百个取值，因此筛选入口支持搜索与分页，不一次性铺开。

书籍卡片在新标签页打开详情，原列表的筛选、页码和滚动位置保留。分页浏览提供页码输入，可按回车或点击“跳转”；输入、总页数与跳转按钮组成紧凑单行，窄屏时可将整组移到下一行，组内不拆行。页码须为正整数，已知总页数时不得超出范围，非法输入显示说明且不翻页。跳页保留当前筛选与排序。网络书源未提供总页数时不显示虚构的总数，允许输入正整数请求对应页。加载期间禁止重复跳转；单页或空列表不展示无用的跳页控件。

文件目录按已入库书籍的原始文件路径组织目录树，左侧展开目录，右侧分页显示选中目录中的书，默认只显示当前目录，可选择包含子目录。目录计数包含后代目录并按书去重；压缩包成员归到原压缩包所在目录。目录名称与计数也遵循私藏书权限及来源可用性规则，不展示不可见书籍的独有目录。浏览不扫描磁盘、不导入、不复制或保留解压副本。目录位置使用数据库索引，按目录查询、计数并分页，不周期性重读全库。导入、移动、改名、删除和来源可用性变化登记受影响书籍，由独立目录索引维护任务在后台增量处理，目录查询前继续同步残余变化；首次建立索引后重启继续复用。手动刷新处理尚未同步的变化；每次响应继续按当前权限、书目存在性和确认缺失状态过滤。

### 5.6 回收站

公开书删除后进入回收站，可查看书名、作者、格式、文件大小与删除时间，并恢复原书号及分类、简介和格式记录。托管书籍文件暂存于回收站；仅索引书籍只保存小型元数据快照，外部源文件不复制、不移动、不删除，永久删除索引回收站条目也不触及外部源文件。私藏书保持永久删除规则，不向管理员回收站暴露。恢复遇到已有书号或文件时拒绝覆盖。可恢复删除保留扫描记录，避免正在进行的扫描立即重新导入该书。旧条目没有元数据快照时不能保证恢复已丢失的数据库记录。

回收站可以查看、统计占用空间并清空。**清空不可恢复**，界面必须明确提示。

回收站与上传临时目录都做**路径安全校验**：目标必须是绝对路径、不能是根目录、不能是符号链接指向别处，否则拒绝清理。这条防的是配置错误导致的误删。

### 5.7 计数

书库为每本书维护访问量、游客访问量与下载量，用于热门榜单。计数是**全站聚合**，与读者个人的阅读状态无关。演示模式下不写入计数。

书籍列表支持默认排序和文件大小升序、降序。大小采用每本书可用格式中的最大字节数，不合计多个格式；未知大小排在最后，大小相同时保持稳定顺序。分页列表在完整筛选结果排序后分页，改变排序回到第一页并保留筛选条件。

书籍详情按当前版本的每种格式显示容器内实际存储目录和文件名，ZIP 成员同时显示归档内部路径；仅管理员或有管理权的读者可见。来源暂不可读时保留登记位置，不因查看详情而访问磁盘或解压文件。
