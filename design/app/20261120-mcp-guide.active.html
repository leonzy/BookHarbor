MCP 配置指南按钮

创建日期：2026-11-20 · 所属模块：app · 影响范围：插件中心、i18n、MCP 文档

需求来源：用户指出插件中心看不到 MCP，并要求用小按钮展示配置方式。

1. 原始诉求

“现在插件中心页面看不到：http://192.168.1.96:8850/admin/settings/plugins”“搞个小按钮，点击后显示如何配置”“应该还要说明使用方如何配置这个mcp吧”

当前 8850 实例仍运行未包含 MCP 的旧版本，需要后续单独部署。界面改动解决部署后用户不知道如何配置的问题。

2. 目标与非目标

  • 在 MCP 卡片提供不影响启停流程的「配置指南」小按钮。
  • 弹窗展示连接凭据、远程和写入开关、当前站点 HTTP 配置及现有容器 stdio 配置。
  • 适配桌面和移动端，提供中英文及俄文文案和自动化测试。

非目标：不自动显示或生成真实令牌，不改变插件启停和连接保存逻辑，不创建新容器或服务，不在本次未确认前修改生产实例。

3. 方案

  • 新增独立 McpGuideDialog.vue，只在插件 ID talebook.combo.mcp 的卡片展示。
  • HTTP 示例使用当前页面 origin 拼接 /mcp；stdio 示例直接在现有容器运行 booksvr mcp --user 用户名，复用主服务权限索引。HTTP 令牌说明仅在 HTTP 标签显示。
  • 指南文本使用 i18n，初始状态查询不返回令牌；使用者显式生成或显示本人令牌后才组装 HTTP 配置，关闭弹窗即清除页面内存中的令牌。按钮在插件未启用时也可查看。
  • 同步 spec/插件/MCP.md 的界面用词和配置行为；使用文档补齐正确容器路径及客户端示例。

4. 影响范围与风险

影响 app/pages/admin/plugins/index.vue、新组件、三种语言、组件与页面测试、MCP 文档和规格。风险主要是长 JSON 在窄屏溢出、弹窗嵌套和示例路径错误；使用横向滚动代码块、独立弹窗及当前镜像实际路径处理。

5. 测试计划与结果

验证与主程序部署均已完成。

  • 组件：2 条 MCP 组件测试通过，覆盖当前站点 HTTP 地址、stdio 参数、默认无真实令牌和关闭。
  • 静态检查：ESLint 0 errors；三种语言 JSON、编译安全与翻译检查通过；27 篇领域规格校验通过；Nuxt SSR 生产构建通过。
  • 真实界面迭代：发现 configuration_mode=connection 未进入既有实例连接表单，导致无法填写令牌；已复用 form 的既有入口，并补齐远程、写入、令牌和读者编号文案。个人连接隐藏仅属于实例连接的 user_id，新增页面用例覆盖保存与个人配置。
  • 回归：完整仓库复测发现 MCP 新增的两个 MDI 图标未注册，已补齐并通过定向测试。早先漫画阅读器失败来自测试容器未挂载仓库根目录，不是产品回归。
