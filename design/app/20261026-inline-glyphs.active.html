MOBI 正文字形图片缩放

小型字形位图跟随相邻文字字号，保留纵横比与插图原有排版。

2026-10-26app / ReadestACTIVE

原始诉求

用户书号 413976《宋词鉴赏辞典》的“蘋”字被当成 93×105px 图片展示；实际原图 39×44px。用户要求跟随周围字号、保持比例、不能影响正常插图与活动导入，测试通过后部署并提交推送。

决策与边界

只对保守判定的旧 MOBI 内联图字施加专属类：recindex 图片、带旧式宽高属性的段落、行内文字上下文、原始小型位图，排除整页图、图注容器、链接图、浮动/定位图、百分比或视口尺寸图及大图。不扩大全局图片缩放。沿用已有 has-text-siblings 逻辑，其余格式、普通插图和封面规则保持原样。

识别 FONT / SPAN 等行内文字包装；相邻文本的实际字号与图片父容器字号之比写成 em，图片宽度按原图比例乘相邻文字字号计算、竖排按一个字宽，均用 auto 高度；保留最大宽度限制，宽图缩至行宽时高度也同比收缩。专属 CSS 需要覆盖旧 MOBI :only-child 的 !important 尺寸规则；字形图片自身的文字基线/主题处理沿用已有机制。图像异步加载只处理当前图片，不重新遍历整章，保留先读后写批处理。

实施与部署

在固定 Readest 源码与已生效的 0001–0004 后新增 0005 补丁，含检测逻辑与测试；由正式构建及 sync.mjs 更新哈希资源，不手改压缩 JS。不修改书文件、数据库、后端或导入任务；只原子更新 Readest 静态资源，保留旧哈希供已打开的阅读页使用。部署前后核对导入 PID 与 /proc 启动时间。

影响范围：Readest style / 新增内联图字辅助函数与回归测试、构建来源清单、spec/阅读器.md。限制：保守识别未明确的小图时宁可保留原排版；不使用 OCR，不改变图片所表示的字。
