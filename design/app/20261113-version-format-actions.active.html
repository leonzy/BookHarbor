阅读与设备发送选择版本格式

创建日期：2026-11-13 · 模块：app / booksvr · 状态：ACTIVE

原始诉求与目标

点击阅读或发送到设备时，可以选择同一作品中的具体版本和格式。单文件直接阅读，多文件先选择；发送窗口明确选择文件。

设计决策与边界

依据现有授权自主确定：选项由详情返回的当前版本和可见同作品版本构成，以书籍 ID 和格式标识，不合并同格式的不同版本；显示格式、大小、版本编号。阅读只提供已有阅读器支持的入口，不自动转换。发送明确传递格式；无效或丢失格式报错，禁止回退成另一文件。旧客户端不传格式保留默认行为。使用已有权限校验，不暴露额外存储路径，不修改书库或后台任务。

方案与影响范围

前端共用文件选项生成器，阅读选择弹窗与发送格式选择。后端发送接口接受 format 并校验属于目标书籍。涉及 spec/书籍.md 、spec/插件/发送到设备.md 、spec/阅读器.md。无库表迁移。漫画格式参数贯穿选择、清单、图片和进度请求；同作品版本补充媒体类型。
