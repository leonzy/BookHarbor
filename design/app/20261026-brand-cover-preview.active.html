BookHarbor 品牌与封面预览

将站点旧标题改为 BookHarbor；所有书籍封面支持点击放大。

2026-10-26appACTIVE

原始诉求

用户明确存储已改到 /vol2/1000/bookharbor/，界面仍显示 TaleBook，封面太小无法看清。

目标与设计决策

复述与 grill：现有用户授权已明确品牌和点击行为。采用封面预览与书名详情两个独立入口，避免点击图片触发新标签；保留详情新标签行为。预览适配屏幕，提供放大、缩小、重置、关闭、Esc、背景关闭和键盘操作，错误可重试，关闭归还焦点；全局仅一个弹窗。小图尽量请求同一本书的大封面。组件实测确认当前 Vuetify 图片组件不支持 tag=button，故使用原生 button 包装图片；列表卡片、播放器与选择器拆开封面与导航/选择按钮，确保无嵌套交互。保留既有图片尺寸和说明布局。预览关闭频繁，禁用入场缩放动画；高倍缩放后把滚动区域置中，避免宽容器留白导致图片移出可见区域；外部封面不猜测其大图端点。界面审查发现长书名可能挤占弹窗高度，按 MEDIUM 处理：标题最多两行并保留完整 title/无障碍名称，弹窗采用列式 flex，图片区域占剩余空间并独立滚动，通过单个 ResizeObserver 和图片固有尺寸计算适配比例，保证首次预览完整显示、缩放始终以图片中心定位；静态 E2E 抓到 Vue 数值样式缺少 px 导致图片未实际变大的问题，改为内部数值计算、输出显式像素单位，并由尺寸增长断言验证。补充 320px 长标题测试、弹窗焦点循环测试，并让重置按钮的可访问名称包含当前可见倍率。不改原书和数据库结构，不重启导入进程。

核对容器现有挂载，再通过站点设置 API 更新实际旧标题；保留自定义标题机制及内部兼容协议名称。部署与维护全部使用新目录，旧目录不再写入。

影响范围与实现
