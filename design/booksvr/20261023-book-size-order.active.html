书籍列表按大小排序

复用已有文件大小，按完整筛选结果排序后分页。

ACTIVE创建：2026-10-23验证与部署：2026-10-24booksvr · app

原始诉求与目标

各种书籍浏览和列表页面增加按大小排序，确认数据库已有大小字段。支持默认、从小到大、从大到小；保留现有筛选、权限、分页和新标签页行为。沿用会话中测试、部署、提交与推送的授权。

影响范围：本地书库、分类下书目、搜索、最近、热门、目录、私有、收藏、书架、阅读列表及管理书籍。首页推荐和外部服务没有本地大小的结果维持原语义。领域规格同步更新：书库、用户、阅读状态。

关键决策与实现

已有格式大小

book_formats.size 优先；Calibre-only 格式回退 data.uncompressed_size。

增量排序投影

每书最大可用字节数，未知最后，相同大小按 ID 降序。

数据库排序分页

筛选与权限生效后取页；卡片大小采用相同来源优先级。

  • book_sort_sizes 维护 book_id、size、known，book_size_asc / book_size_desc 为覆盖索引。首次升级批量填充后再建立索引，后续仅对变动书籍重算。格式新增、修改、删除及来源 missing 变化由事务内触发器维护；正常来源心跳不重算全库。
  • 请求 sort=size_asc / size_desc 经白名单解析。全库、分类、目录及管理列表先排序后分页；书架、在读和已读保持完整个人集合再排序；固定历史记录组在已完整返回的小集合内排序。
  • 格式页复用已有计数投影并显式使用大小索引；热门列表和私有权限增加部分索引。无筛选总数扣除真实存在的私有书目，并避免与来源缺失重复扣数。
  • 大小读取共享 requested CTE，批次最多 500 个参数，兼容旧 book_formats 缺少 size 列的薄 schema。网络收藏 DTO 也返回 format_sizes。
  • 共享 Vuetify 选择器和三语言文案；排序改变重置第一页并保留筛选，路由保存状态。个人列表用序列号保护慢响应，私有页明确发送 scope=private。
  • 不扫描或复制原文件，不重跑导入。升级只添加派生表、索引与触发器。已有账号、设置、来源挂载、书籍及导入状态保留。

备选与取舍

不累计同一本书多个格式的总大小，避免重复计算；不用当前页排序代替完整集合排序。首次启动构建投影会增加升级等待；隔离 CPU1 冷启动曾测 64.123 秒，重复启动不会重新填充全库。
