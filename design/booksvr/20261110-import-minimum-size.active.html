导入文件最小大小过滤

创建：2026-11-10 · 模块：booksvr / app · 状态：ACTIVE · 需求来源：小于设置大小的文件不扫描、不入库，避免 README 被当作电子书。

原始诉求和目标

增加管理员可持久保存的最小导入文件大小，默认10 KiB，0为关闭；小于阈值跳过，恰好等于阈值可导入。用户追加要求：保存设置后核查既有书籍，自动移除小文件的书库登记，保留原文件。所有目录扫描、自动发现、ZIP内书籍和已待导入记录使用同一规则。

决策核对与方案

  • 单位明确为KiB（1024字节），前后端校验非负整数。
  • 扫描在哈希和元数据分析前过滤；ZIP按成员解压后大小判断，外层ZIP不按压缩大小过滤。
  • 生产扫描服务读取最新保存值，保存后下一文件生效；外部手工配置变更最多一秒内生效，单个ZIP展开保持开始时的筛选版本，不取消任务或清理队列。入库前再次校验实际文件大小，旧待处理记录归已跳过并给出原因。
  • 仅修改导入设置界面和扫描/入库流程，不删除任何原文件，不修改来源同步的缺失判断。
  • 放宽阈值后需允许未入库的小文件重新进入扫描；目录扫描缓存须包含筛选策略版本。

影响范围

booksvr扫描与配置、app导入设置弹窗及翻译、spec/书库.md，必要时系统配置规格。保持原有工作区OPDS与部署脚本改动。

实施前验证计划

原定验证项：边界值、普通/增量/全量/ZIP、旧待入库阻断、设置校验与持久化、运行时热生效、阈值放宽重扫、组件及真实浏览器渲染。按项目要求应用interface-review full审查全部分支和工作区差异；纯代码差异不冒充视觉验收。

追加需求：既有书库后台清理

用户明确选择自动从书库移除、保留原文件。保存阈值创建持久核查代次；按记录大小索引筛出候选，分页游标与计数存入书库，重启继续。每个候选重新获取源文件并确认实际大小，缺失、不可读或挂载保护中的来源跳过。多格式书只删小格式登记，最后一个版本移除时删除书目数据库记录；绝不删除、移动、重命名源文件。扫描历史标记已跳过并保留原因，阈值放宽可重扫。

核查与导入共用后台工作互斥；繁忙时等待，处理每个文件后释放，最多每秒10个，完整来源核对运行时暂缓。单个格式变更与进度在书库同一事务提交，避免重启漏记或重删。进度直接接入现有导入状态轮询，显示候选、已检查、已移除版本/书目、不可读和错误。

核查安全边界细化

核查代次仅在导入设置明确提交大小字段时创建，避免其他管理页整表保存默认值意外触发全库移除。格式删除与核查计数同一书库事务提交，并记录持久跨库待办，重启可补写扫描记录的已跳过原因。手动变更配置使当前任务阈值不一致时停止旧任务，等待显式保存重新核查。来源不可读/挂载保护的文件仅计为保留，不按数据库中陈旧大小直接移除。

界面审查迭代

按 interface-review full 与 better-interface 六域规则自审，发现新增字段非法时禁用整个保存按钮，不利于键盘用户定位错误；改为提交时聚焦该字段并显示相邻错误，不发送请求。补全取消脏值比较中大小字段，避免误丢输入；保存按钮采用警告语义及“保存并核查书库”明确后果，旁边说明保留原文件。完成修正后重新审查与浏览器验证。

渲染与颜色修正

Chromium 隔离页面已验证保存、刷新、0禁用、非法输入和320px布局。视觉检查发现新增警告使用默认橙色文字与浅橙背景，对比不足，保存按钮白字橙底也不够清晰；修正为语义警告底色配高对比正文和深色按钮字，只作用于新增控件。截图等待过渡结束，避免窄屏重开弹窗时截到半透明中间态。增加独立核查进度轮询，避免在导入空闲时原轮询停止导致进度不更新。

性能复核

核查每秒最多10个文件，但不能因此每秒解析20次完整站点配置。复用一秒配置快照，并由保存版本号立即失效；单文件仍复查挂载与真实文件身份。候选计数使用大小索引，处理使用递增格式ID游标，不重复读取全库或保存全库对象。任务完成后只保留固定状态与移除待办，不持有文件字节。

最终查询与排队复核

候选总数走大小索引；下一条候选强制按格式主键范围递增，避免优化器每次筛选全部小文件后重排。跨库待办按 applied 索引查找，避免反复扫描已应用的审计记录。保存后先创建核查状态，再等待导入互斥/来源核对，繁忙时也能显示真实初始候选与进度。

尺寸新鲜度复核

既有格式记录的大小可能仍是入库时的值；候选同时纳入来源同步记录的当前尺寸。普通文件实际已缩小时不会因旧尺寸较大而漏查，ZIP 引用仍用成员尺寸，不能用整个压缩包尺寸替代。候选总数合并两个大小索引结果，单条处理仍按主键游标；物理核查后只凭实际尺寸和稳定身份决定是否移除。
