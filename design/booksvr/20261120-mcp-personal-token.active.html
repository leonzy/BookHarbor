MCP 个人令牌

2026-11-20 · booksvr · ACTIVE

原始诉求与目标

登录后使用自己的身份。系统生成令牌与可复制配置，免填账号编号、令牌和远程开关。

方案

管理与个人插件入口共用个人令牌页。凭据按当前会话绑定并加密保存，GET 只返回账号和状态。显式请求才显示令牌，支持重新生成。默认只读，写入显式开启。保留旧连接。规格与使用指南同步。

测试

Go MCP 测试和 vet、两条组件测试、Nuxt 静态构建、27 篇规格通过。两账号测试验证用户隔离、默认只读、轮换失效和写权限，GET 不返回令牌。线上 Chromium 通过管理入口、生成、复制、调用实际 /mcp、个人入口回显及 390px 宽度检查。页面实测发现请求体没有序列化，补上 JSON 后复测通过。反代覆盖了禁止缓存标记，MCP 个人接口使用独立 location 后确认返回 private, no-store。保留元数据、阅读器、插件服务和 nginx 主进程，主服务完成更新。发布备份在 /data/maintenance/20261120-mcp-personal-b5443138-6fde3 。工作区的其他开发内容和未完成界面审查不在本次验收内。
