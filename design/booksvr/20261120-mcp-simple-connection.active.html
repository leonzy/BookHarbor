原始诉求与目标

HTTP 只配置地址和身份凭据。stdio 只配置要启动的命令和读者身份。提供可抄用的实际配置并上线测试。

方案

HTTP 使用现有个人令牌。stdio 信任本机进程权限，按读者用户名或编号解析并启用书库访问范围。默认只读，可显式打开写入。标准容器路径默认可用，保留环境变量和参数覆盖。影响 spec/插件/MCP.md，配置指南 WIP 同步修订。

测试

Go MCP HTTP 与无连接 stdio 测试通过。前端组件两例及静态构建通过。主服务发布后通过实际入口验证 Bearer、初始化、工具发现、查书、详情、三条推荐、三条阅读记录、编辑预检和令牌撤销。首轮 stdio 遇到权限表迁移 SQLITE_BUSY，改为复用主服务权限表后，使用 talebook 身份和 --user admin 读真实书目成功，默认隐藏写入工具。实际 BOOX 设备暂不可达，真实服务器上传 570287 字节 EPUB 到临时回环接收端，任务完成。保留五个独立服务原 PID；主服务停止超时由 Supervisor 强制结束后成功启动。生产未改真实书目。部署备份位于 /data/maintenance/20261120-mcp-2d1854ed-eac1d 。
