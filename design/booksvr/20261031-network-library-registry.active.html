原始诉求与证据

已登录访问 /api/network/sources 返回 exception，正常启用的 source 插件均存在。常规启动装配 NetworkConfig 与 OnlineComicConfig 时遗漏 Catalog；默认构造 NewRuntime(...,nil) 得到空注册表，数据库连接列表仍有插件，而 Registry.Get 失败。既有 handler 单测注入自定义 Catalog，未覆盖正式装配。

目标与设计边界

网络书库和在线漫画复用已经注册的 provider，保留当前用户、启用状态、权限、凭据与连接策略。共享组装函数同时供正式服务与维护监听器使用，避免单独热修列表而搜索/浏览/正文仍坏。设置按请求读取，保存到本地沿用既有书源保存实现，不启动额外目录监控或导入器。原导入和阅读进程不重启。

方案与影响范围

抽出 networkLibraryRouteSpecs，注入 Catalog 和 SaveOnline；正式服务与 metadata-only 维护服务共用这套标准及旧别名、漫画 API 路由。维护部署复用已有有界服务更新步骤，独立脚本仅新增网络 API 和在线漫画页面 Nginx 转发，支持重复执行与失败恢复。不修改尚未完成的 OPDS 补丁，不把它提交为完成。修改 spec/网络书库.md 与维护模式说明。
