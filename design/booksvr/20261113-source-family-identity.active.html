原始诉求与证据

《大国重工》EPUB 与 MOBI 都是佚名、无 ISBN；源路径同目录、同 Q047-大国重工 齐橙 文件名，仅扩展名不同。EPUB OPF 无作者，开头是正文，没有可直接提取的署名。旧规则只接受题名加作者或 ISBN，漏掉配套文件证据。admin 登录这两个详情均正常显示存储位置；游客 API 不返回路径，leonfn 与 IP 登录状态不共享。

目标与设计决策

  • 采用数据库中已登记的普通格式文件路径作为辅助证据：目录及完整文件名主体完全相同，且扩展名与登记格式一致。比较书名仍需相符；已知作者或 ISBN 冲突不允许该回退。
  • 不按文件名猜作者，不改元数据、书号、阅读记录或原文件。人工归组继续保护。
  • 来源键只在本次比较中计算，每书最多十六个登记格式，超过上限不采用来源证据；压缩包引用不采用这条规则，避免把整个归档当同一书。来源键不从网络候选接收。
  • 可靠子集支持实际源文件见证，避免无作者配套对被同名外部候选阻挡；仍采用已有原子自动组、歧义交集及有界邻域。
  • 格式插入、路径更新和删除按代次入队。新增独立 sources_v2 固定上界游标，每批两百条比较键，只为同题名且缺作者的历史记录重新入队；不重置作者、导入或元数据补全游标，不反复查文件系统。
  • 路径权限保持原样；不为游客暴露目录。向用户说明需在当前主机地址登录 admin；无前端代码修改。

影响范围与风险

bookidentity、library 归组与后台维护，spec/书籍.md。来源路径会进入内部签名，但不是公开书籍响应。相同命名仍可能错误，因此明确身份冲突优先；不同目录同名文件不能仅靠来源键相连。原有 OPDS、部署脚本、其他方案保持独立。

完整作者见证的组合边界

补充三条记录边界：A 缺作者、与 B 为同源配套文件；B 有完整作者；C 同题名同完整作者但来自其他目录。A+B 的来源证据与 B+C 的作者证据应该能被真实的完整作者 B 同时解释，不能因 A 与 C 没有直接来源路径相同而整组回退。仅当完整作者见证能逐一直接支持所有成员、且包含实际来源配套证据时，允许该星形集合；全部缺作者的路径链仍不能作为见证。该分支不按多个半名单传递作者，明确冲突仍拒绝。部署中的初版 sources_v1 游标保留，最终规则采用 sources_v2 新游标重核已处理范围，不清队列或重置旧游标。
