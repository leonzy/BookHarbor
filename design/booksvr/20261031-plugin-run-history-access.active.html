插件执行记录归属与历史查询修复

2026-10-31 · booksvr · ACTIVE · 用户点击最近失败记录 #94285 显示不存在

原始诉求与目标

全库元数据进度中微信读书的最近失败链接存在，但详情页返回 Plugin run was not found。允许管理员从该入口查看实例与其自己个人连接的记录，保留其他用户隐私隔离；旧记录按主键定位，不受最近一千条限制。

方案与边界

管理员只读执行列表/详情的范围为实例连接与当前管理员自己的个人连接。普通用户仍只能看自己，管理员执行动作与重试权限不扩大。查询改用已有 GetPluginRunByID，避免扫描同连接全部最近记录。维护模式显式注册四个 GET 列表/详情路由，通过原鉴权中间件；新执行记录 API 路由交给维护中的元数据服务，不重启导入或阅读服务，不重建容器。

涉及 spec/插件/插件平台.md 与 spec/元数据.md。原有 OPDS 草稿保持未提交。新增部署脚本单独维护执行记录代理，不纳入未完成的 OPDS 变更。

测试计划

首次生产渲染仍返回旧错误，定位为维护 Dispatcher 缺少路由而回退旧服务；补充完整 Dispatcher 的管理员/普通用户/访客集成回归，禁止仅以 handler 测试通过宣称上线。验证覆盖：管理员实例/自己/他人，普通用户自己/他人/实例，缺失记录，超过一千条的旧记录；列表与详情范围一致，现有权限与敏感输入过滤；代理配置幂等和回滚；Go 回归、Linux HTTP 整包、vet、实际 #94285 页面与进度链接。部署前后进程/游标核对。interface-review full 审查全部本地差异并记录未验证的界面范围。
