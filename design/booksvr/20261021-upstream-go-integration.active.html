实现决策与迭代

上游 17 个非合并提交按功能吸收，没有直接覆盖当前分支。登录弹窗、书卡、简介 HTML 文本化与响应式历史卡片同步；保留新标签页、大小、完整扫描、ZIP、仅索引、来源保护和统计口径。前端新增 entities/ultrahtml 的版本与锁文件一致。推荐使用每组最多 512 候选与有限读者种子，先过滤私有和来源缺失，再按作者/标签/丛书/热度/时间评分并做多样性限制。时间查询增加复合索引，批量加载历史元数据。

停止接口 GET/DELETE /api/admin/import/task 仅管理员可用。通过任务上下文合作取消，并保存 import_control.paused 与 cancelled 意图；任务代次避免立即重试丢失，正常停机仍保存未完成任务。独立源目录核对不被手工停止波及。短状态文案改为“已暂停”，不在停止时显示“处理完毕”。

HTTP Python、旧 ORM、旧应用测试与 uv.lock 删除，resources 独立保留。Go bootstrap 提供幂等增列和账号 schema，启动自检不再执行 Python 应用。Python 仅保留 Calibre/监督进程/升级管理/开发校验。开发入口与 CI、升级导出路径适配原生二进制。升级包保持可执行位，继续保留哈希静态资源供已打开页面加载。
