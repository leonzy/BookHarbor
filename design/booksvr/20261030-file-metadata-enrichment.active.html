文件优先元数据提取与后台补全

创建日期：2026-10-30 · 模块：booksvr · 状态：ACTIVE

原始诉求

按内嵌元数据、版权页正文、文件名、联网检索的顺序补全 ISBN、作者、出版社。修复联网检索和自动补全，历史书籍限速处理，不覆盖人工修改，不影响正在运行的导入；测试后部署、提交和推送。

目标与设计决策

现场已有 439948 本书，identifiers 和 books.isbn 均无 ISBN；TXT/PDF 无解析器，EPUB 仅读取 OPF，导入丢失 ISBN、语言及第二位作者；GET refer 错误地要求 JSON 请求体。auto_fill_meta 已开启但未接执行。

逐项边界核对：不重启导入主进程；独立维护监听仅接管元数据接口，后台单路低优先级执行。文件只读，不生成转换或解压缓存；对历史非空字段保守保留，今后的人工写入（含明确清空）按字段锁定。自动填充在短事务内再次检查锁与当前值，不依赖读取时的快照。ISBN 校验校验位，正文只采信明确标签，不把任意数字、站点或制作人当作作者。

方案

统一文件提取供新导入及补全调用：结构化 EPUB/MOBI/AZW3/DOCX/FB2/HTMLZ 优先；版权页与文本有限读取；PDF 属性及前若干页文本使用限时外部工具，扫描版无文本不自动 OCR。ISBN、作者、出版社优先补缺，语言、日期、简介等可用内嵌值一并保存。联网通过已启用插件，强 ISBN 或书名作者匹配后补缺，不直接套用第一条候选；失败保留原因并退避。持久化游标优先新书再处理历史，单路限速、有重启断点和工作者租约，不反复全库扫描。

部署：并行维护进程使用原认证与插件配置，仅创建本功能的小型扩展表，不执行全库迁移或导入工作者；Nginx 只转发编辑和参考信息接口。原主进程与原生阅读器 PID/启动时刻部署前后核对。新版常规服务也装配相同工作者，租约避免重复。

影响范围：scan、library、httpapi、CLI、spec/元数据.md、spec/书库.md；无前端布局更改，元数据消费者和错误流程需 full 界面审查。grill skill 本地不存在，以上逐项核对使用已授权需求及保守判断，无待用户决定边界。

联网协议补充核对

消费者审查补充：前端 GET 无请求体、套用候选使用 URL 编码表单，分别兼容，不扩大其他写接口解析范围。自动补全设置文案改为缺失字段并说明历史限速；仅信息开关关闭时可补缺失封面，沿用原子不覆盖的 StoreCover，最多三个能力调用，现有封面始终保留。对应中英俄文案和实际页面需构建、渲染验证。

Open Library 2025 年起缩减 search.json 默认字段，现有调用没有请求 ISBN 字段，并从作品级结果取任意 ISBN，容易丢掉匹配线索或混淆版本。按官方 Search API 与 Books API 文档，ISBN 查询先走精确版本 Books API，普通搜索显式请求需要的字段；精确版本信息直接用于确认和补缺。参考：https://openlibrary.org/dev/docs/api/books 与 https://blog.openlibrary.org/2025/01/16/api-search-json-performance-tuning/ 。Books API 为官方仍提供的旧兼容接口，未来需关注弃用；本次不使用全字段大响应。Calibre 元数据源在精简运行时没有插件执行器，保持明确不可用提示，不恢复已删除的 Python HTTP 服务。

页面验收迭代

首次界面部署验收发现：维护进程使用私有 umask，解包产生的语言包父目录为 0700 且属于 root，Nginx 无法读取，原静态回退把失败伪装为 200 HTML。已先恢复原 SPA 入口；Go 元数据服务和补全任务保留，导入与阅读进程未动。修复部署器对公开 Nuxt 和语言包目录逐项设置 0755、文件 0644，保持维护备份目录私有；给正式 Nginx 模板及当前部署增加语言包严格 404 与不缓存 HTML 回退的规则。新增实际执行生成部署程序的私有 umask 回归用例，验证目录可读、版本标记保留和旧哈希资源保留。影响范围追加 conf/nginx、三语设置说明和独立部署脚本；不恢复 Python HTTP 服务，Python 仅用于已有容器运维脚本与测试。

管理员入口验收补充

真实管理员登录后，书籍详情仍返回 is_owner=false，界面因此隐藏管理菜单，尽管元数据编辑接口允许管理员执行。根因是详情只调用普通所有者判定，没有合并管理员身份；既有问题直接阻断本次联网补全入口。将详情权限与既有管理员操作权限对齐，增加管理员、普通读者和游客测试；维护监听追加单本详情路由并继续保留逐书可见权限与原始下载路由。实际请求进一步确认 Nginx 主进程以 talebook 用户运行，root 安装器写出的站点配置若为0600，nginx -t（root）通过却在主进程重载时失败。补充发布与回滚均设站点配置0644，私有备份仍为0700，并通过生成程序执行测试验证。重复部署也补充显式启动已停止的元数据进程并等待端口就绪，仅此辅助进程可重启。
